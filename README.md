# Мой ТПУ

Хаб студента ТПУ

## Стек

Vite React 19 TypeScript react-router.

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Устройство

[ARCHITECTURE.md](./ARCHITECTURE.md)

| Папка | Что внутри |
|-------|-----------|
| `src/app` | каркас приложения и роутер |
| `src/pages` | страницы |
| `src/board` | доска виджетов главной |
| `src/api` | типы контрактов и моки |
| `src/shared` | UI-примитивы |
